# Expense Tracker

A full-stack Expense Tracker application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). The application allows users to track their income and expenses, categorize transactions, monitor spending habits, and view financial summaries through an intuitive dashboard.

## Features

- User authentication and authorization (JWT-based)
- Add, edit, and delete income and expense transactions
- Categorize transactions
- View transaction history
- Dashboard with financial summary
- Monthly income and expense tracking
- Responsive user interface
- Secure REST API
- Persistent data storage with MongoDB

## Tech Stack

### Frontend
- React.js
- React Router
- Axios
- CSS / Tailwind CSS (optional)

### Backend
- Node.js
- Express.js
- JWT Authentication
- Bcrypt.js

### Database
- MongoDB
- Mongoose
